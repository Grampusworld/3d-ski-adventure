# 3D 滑雪大冒险

一款在浏览器里玩的 3D 滑雪跑酷游戏（灵感来自 Haste）。雪崩在身后越追越快，你要一路冲下雪山，冲过山脚的终点线。

**在线试玩**：https://grampusworld.github.io/3d-ski-adventure/ （电脑浏览器，用键盘和鼠标玩）

## 玩法

- **加速**：在空中按住 Shift 俯冲，落在暖色的下坡上就是完美落地，速度大增。
- **空中耍酷**：点按空格摆姿势、长按空格做动作；同一次腾空里连着做，分数倍率越来越高。没做完就落地会失误、大幅减速。
- **雪橇车**：碰到小木屋门前发光的圆环，进屋拿一辆雪橇车（雪地摩托）。速度锁定在 350 km/h 起步，空中每做完一个动作升一档，最高 700 km/h；硬着陆或撞上障碍时它会替你挡一次。
- **躲开障碍物**：树、石头、小木屋、缆车塔架会让你大幅减速。

## 操作

| 按键 | 作用 |
|---|---|
| W A S D | 移动（W 往前跑，S 刹车） |
| 鼠标 / ← → | 转向 |
| 空格 | 跳；空中点按摆姿势、长按做动作 |
| Shift / 鼠标右键 | 空中俯冲；耍酷时按下取消 |
| Esc / R / M | 暂停 / 重新开始 / 静音 |

第一次打开游戏会自动播放新手教程，主菜单里也可以随时重看。

## 本地运行

需要 [Node.js](https://nodejs.org/)（20.19 或更高）。

```bash
npm install
npm run dev
```

然后在浏览器里打开终端显示的地址（默认 http://localhost:5173）。

打包成静态网页：

```bash
npm run build
```

生成的文件在 `dist/` 目录。推送到 `main` 分支后，GitHub Actions 会自动打包并部署到 GitHub Pages（见 `.github/workflows/deploy.yml`）。

## 技术

- [Three.js](https://threejs.org/) + [Vite](https://vite.dev/)，不用游戏引擎
- 地形、角色、雪地摩托、小木屋等所有模型都用代码生成，没有外部模型文件
- 音乐和音效全部用 Web Audio 实时合成
