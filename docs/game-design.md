# 3D 滑雪大冒险：设计文档

> 版本：v0.9（2026-10-17）
> 状态：M0 灰盒原型已完成，已部署到 https://grampusworld.github.io/3d-ski-adventure/；开放雪原、雪崩、滑雪站起点和画中画的第一版已完成，待试玩调整
> 游戏名：3D 滑雪大冒险（原名"雪崩奔跑"）

---

## 1. 概述

**一句话**：从山腰的滑雪站出发，在开阔的雪原上高速冲下山，靠俯冲和完美落地把高度换成速度，赶在身后的雪崩吞没你之前冲到终点。

**参考作品**：《Haste: Broken Worlds》（Landfall）

**发布形式**：网页游戏。部署成一个公开链接，点开就能玩，不用下载安装。

**目标平台**：PC 浏览器（Chrome / Edge 优先），键盘加鼠标操作。移动端暂不支持。

### 设计支柱

1. **玩地形，操作要简单**：核心乐趣是看懂地形、自己选路线，在对的地方起跳和俯冲，像冲浪一样。动作数量少，深度来自地形。
2. **速度感**：速度就是生命，也是奖励。所有视听反馈都为"快"服务。
3. **短局、反复挑战**：一局 3～5 分钟，失败后马上能重开。

| 输入 | 动作 |
|---|---|
| W A S D | 移动 |

## 3. 核心机制

### 3.1 速度系统

| 状态 | 规则 |
|---|---|
| 平地 | 逐渐加速，最多到巡航速度 |
| 下坡 | 按坡度加速，可以超过巡航速度 |
| 上坡 | 按坡度减速 |
| 空中 | 基本保持水平速度，受重力下落 |
| 俯冲 | 下落速度大幅增加，为完美落地蓄力 |

### 3.2 落地判定（核心爽点）

| 落地类型 | 条件 | 结果 |
|---|---|---|
| **完美落地** | 落地时处于俯冲状态，地面是下坡，且坡面朝向和移动方向大体一致 | 下落速度的一大部分转成前进速度，再额外加速；配强烈的镜头、音效和特效反馈 |
| 普通落地 | 其他正常落地 | 损失少量速度 |
| 硬着陆 | 高速砸在平地或上坡上 | 损失较多速度，短暂硬直 |

### 3.3 掉出世界

开放雪原的两侧是爬不上去的雪山，地图内部的悬崖也只会落到更低的雪地上，所以正常游玩中不会掉出世界。掉落判定的代码保留当保险（比如意外穿过地面）：掉到地面以下约 20 米时本局结束，结算标题是"掉出了世界"。

### 3.4 障碍物碰撞

| 障碍物 | 撞上之后 |
|---|---|
| 小东西：插在雪里的滑雪板 | 被撞飞，损失约 15% 的速度，不会停下 |
| 大东西：雪松、小木屋（门前圆环除外，见 3.8）、石头、缆车塔架 | 实心。速度损失约 70%，被强制弹开、顺着障碍物边缘绕过去，硬直 0.5 秒，镜头震一下；不显示文字提示 |

- 在空中撞上也一样处理；从障碍物上方跳过去不会撞到。
- 动物（鹿、狐狸、山羊）暂时不放，模型代码保留，以后再加回来。

### 3.5 俯冲时的角色姿态

- 按住俯冲后，角色的身体慢慢转向自己的运动方向：下落越快，头越朝下，最多接近头朝下（约 80°）；平滑跟随，大约 0.4 秒追上。松开或落地后慢慢回正。参考 Haste。
- 俯冲时镜头逐渐往下多看约 12°，方便看清落点；松开或落地后回到原来的角度。

### 3.6 空中耍酷：姿势和动作

- **触发**：离开地面后的前 0.12 秒内按空格仍算跳（冲出坡顶时起跳不失灵）；之后在空中按空格就是耍酷。去掉"落地前提前按跳"的宽限，避免耍酷时按的空格变成落地自动起跳。
- **短按和长按**：按下空格开始计时，0.25 秒内松开是短按，摆一个**姿势**（0.8 秒）；按住超过 0.25 秒是长按，做一个**动作**（1.25 秒）。一旦开始就会做完，中途松开不会中断。
- **连着做**：一次腾空里可以做多个，但要等当前这个做完；做的过程中再按空格不理会。
- **种类**（每次随机挑一种，不和上一个重复，不需要额外按键）：

| 类型 | 种类 |
|---|---|
| 姿势 | 大字展翅（鳍翅和双脚张开成星形）、单翅敬礼（角色回头看向玩家敬礼）、超人式（身体放平、鳍翅往前伸） |
| 动作 | 前空翻两周、转体两周、后空翻加转体 |

- **按 Shift 俯冲**：耍酷时按 Shift 立刻取消当前的姿势或动作（不给分），转为俯冲，给玩家一个"来不及就赶紧收"的办法。
- **没做完就落地（失误）**：速度立即扣除 70%；这次不算完美落地；没做完的不给分；硬直 0.5 秒，镜头震动，屏幕中间提示"失误！"，配摔倒音效。

### 3.8 雪橇车增益（小木屋）

- **小木屋**：全图 4 间，分别在约 600、1200、1800、2400 米处（前后可挪动 40 米，避开地形特征），左右交替，离中线 60～120 米，需要特意拐过去。体积是原来的两倍：约 16×13 米，高 16 米。门朝上坡方向，也就是玩家跑来的方向；木屋只做小幅随机转动。旁边插几副滑雪板当装饰。木屋本身仍然是实心障碍物，从侧面撞上去照常被弹开。
- **圆环**：门前雪地上一圈暖橙色发光圆环（半径约 4 米），呼吸式闪动，上方有一道淡淡的光柱。圆环和光柱在远处也要能看到（不被远处较粗的地面网格挡住，也不被雾淡掉）。碰到圆环就进屋。每局每间只能用一次，用过后圆环和光柱熄灭，每局开始时恢复。已经坐着雪橇车时碰到新木屋的圆环：原来的雪橇车当场炸掉（碎片加"砰"一声，不显示"雪橇撞毁！"），角色照常进屋，拿到一辆新的雪橇车（重新计时 10 秒、速度回到 350、再给一次 +500 和冲出后的无敌）。
- **进屋（约 1 秒）**：碰到圆环后暂时不能操作。角色自动小跑进门、消失，门关上，配木门吱呀声。镜头先往前推近木屋，再绕过木屋转到下坡一侧，回头看着木屋。
- **屋里（2 秒）**：镜头停在下坡一侧看着木屋，木屋上方显示一个 2 秒的进度圈，配叮叮当当的敲打声。这期间雪崩照常推进，计时和按时间加的分照常累计。如果在这 2 秒里被雪崩追上，就拿不到雪橇。
- **冲出来**：2 秒后，木屋朝下坡那面的门被撞开，角色骑着雪橇车冲向镜头（撞门声加呼啸），弹出大字"+500 雪橇车"。不放慢动作：镜头在原地看着雪橇车冲出来约 0.35 秒，然后用约 0.6 秒平滑回到身后跟随，玩家同时恢复操作。
- **冲出后 1.5 秒无敌**：从冲出木屋那一刻起 1.5 秒内，撞上任何障碍物（树、石头、滑雪板）都直接把它撞飞，速度不变、雪橇车不坏；缆车塔架和小木屋这类撞不飞的直接穿过去。硬着陆也不算：没有减速惩罚，雪橇车也不坏。这 1.5 秒里角色和雪橇车整体发出金色光芒（身上泛金光，周围一圈金色光晕），最后渐渐褪去。
- **持续时间**：10 秒，从恢复操作时开始算，按游戏时间走（暂停时也停）。速度表正上方显示一个红色雪橇小图标加一条横向倒计时条，最后 2 秒闪烁，配滴滴声。时间到时雪橇"砰"地散掉；如果还在空中，角色接着往下落，正在做的耍酷继续做完，落地按平时的规则判定。
- **操作**：在地面上速度锁定 350 km/h（约 97 m/s），上坡、下坡都不变；A、D 照常转向，W、S 不起作用，也不能刹车。空中的重力和俯冲照旧。完美落地照常加分；不管怎么落地，速度都保持 350。
- **五档速度**：雪橇车有五档速度：第一档 350 km/h，第二档 420 km/h，第三档 500 km/h，第四档 600 km/h，第五档 700 km/h。每辆新车都从第一档开始。骑着雪橇车在空中每完整做完一个动作，这个动作得 1500 分（代替平时的 400 分，照样乘耍酷倍率），并且这辆车立即升一档：空中的水平速度马上变成新一档的速度，落地后也锁定在这一档，一直保持到这辆车没了为止。已经是第五档时再做完动作，速度不再变化（仍得 1500 分）。每辆车的档位互不影响：从下一间木屋拿到的新车又从第一档 350 开始。姿势的得分照旧。
- **升档的表现**：几档之间在速度线和视野上原本几乎看不出差别，所以要专门做出来。
  - 切换的那一下（约 1 秒）：屏幕边缘闪一下金光，屏幕中间弹出金色大字"二档加速！420"、"三档加速！500"……"五档加速！700"，速度数字弹一下；视野猛地拉宽再慢慢收回，镜头震一下；速度线突然变多变长、夹着金色的线；车尾扬起一团雪；配加速音效（档位越高音调越高；引擎轰鸣往上拉高、一阵呼啸、一声低沉的"嘭"和一声清亮的提示音）。
  - 第二档及以上：雪地摩托两根排气管一直喷出忽长忽短的橙黄色火焰（档位越高越长越粗）；视野比第一档宽一点（档位越高越宽）；速度线更多、带金色（档位越高越密）；速度数字一直发金光；滑行声更响更尖。
- **撞障碍物**：滑雪板这类小东西被撞飞，速度不变；树、石头、木屋这类大东西一撞，就和硬着陆一样炸掉雪橇。
- **保命符**：坐雪橇时，硬着陆、失误落地或撞上大障碍物，雪橇都会当场炸掉：碎木片四散，"砰"一声加碎木声，镜头震一下，显示"雪橇撞毁！"。角色不减速，也不会被短暂定住。雪橇没了以后，速度可以暂时超过 288 km/h 的上限，再按平时的规则慢慢降下来。
- **耍酷**：做动作时，雪橇和角色作为整体一起翻转；做姿势时，只有角色的上半身摆姿势，腿仍然坐在雪橇上。时长照旧；动作得分见上面的"动作提速"。
- **外观**：按参考图做成低多边形的红色雪地摩托：长约 2.9 米；红色车身配黑色侧板，黑色长座椅，车尾一个红色管状扶手和黑色挡泥板；车头是红色楔形整流罩，带蓝色挡风玻璃、黑色 V 字格栅和两盏车灯，上面是黑色车把；前面两条黑色雪橇板，连着红色转向立柱、黑色摆臂和减震器；后面是红黑相间的履带和一排银色负重轮。企鹅少女跨坐在座椅上，身体前倾，双翅握住车把，双脚踩在两侧的踏板上。坐雪橇时滑行声比平时更尖更响，两侧喷起的雪粉更多；视野和速度线照常跟着速度变化。
- 坐雪橇本身不额外加分（除了拿到时的 +500），结算统计也不加新的行。画中画和雪崩距离提示照常显示。

### 3.7 进阶动作（第一版不做）

冲刺（消耗能量，能量靠完美落地积攒）、抓钩、滑墙。等核心手感验证好玩以后再考虑。

## 4. 雪崩追逐

- **雪崩**：一堵横跨整个地图宽度、几十米高的翻滚雪浪，沿前进方向推进（外观见 8.5）。
- **雪崩倒计时**：玩家起跑后倒数 3 秒，然后雪崩从滑雪站后方的山坡冲下来（详见 5.1）。
- **雪崩速度**：
  - 刚冲下来时有一股初始冲劲，大约 2 秒内吞没滑雪站，然后逐渐回落到基准速度；
  - 之后按基准速度推进，并随时间越来越快；开局 30 秒内略慢（0.8 倍），给新手留空间；
  - **到达时间**：从按下 W 起跑算起，雪崩前沿约 65 秒推进到终点线。作者的个人最好成绩约 55 秒，所以跑得好的玩家大约领先雪崩 10 秒冲线，比 65 秒慢就会在终点前被追上。基准速度据此算出（35.2 m/s），其他雪崩参数不变；
  - 不再有"最大落后距离"：跑得快的玩家可以把雪崩甩开。
- **被追上**：本局结束，结算标题是"被雪崩吞没"。被追上后先播放吞没动画（见 5.5），然后再显示结算。
- **距离反馈**（不靠数字也能感觉到危险）：
  - 屏幕边缘出现白色雪雾和飞溅的雪粒，越近越浓
  - 镜头抖动越来越强
  - 低频轰鸣，越近越响（做音效时加）
  - 界面上显示和雪崩的距离；倒计时数字、"雪崩来了！"和进度条上的雪崩位置用红色

## 5. 单局结构

- 一局有终点，目标时长 3～5 分钟；原型阶段先做约 3 公里（1.5～2 分钟），方便快速试玩。
- 起点是山腰的滑雪站，终点是横跨地图的终点线。
- 流程：开始画面 → 等待起跑 → 雪崩倒计时 → 奔跑 → 到达终点（终点环绕镜头）或被雪崩吞没（停留 2 秒） → 结算 → 再来一局

### 5.1 开局流程

1. **主菜单**：镜头放在滑雪站前方偏下坡的位置，回头看向滑雪站和后面高耸的山脉，缓慢平移；主角站在木屋前面向镜头。
2. 点"开始"后切到正常的游戏镜头，立刻可以操作，没有 3-2-1 倒数。主角站在滑雪站前，正面朝向镜头。默认镜头朝下坡看；用鼠标转动视角，能看到身后的滑雪站和高耸入云、望不到头的山脉。
3. 屏幕正中醒目地显示"按住 W 键开始奔跑"，每局都显示。
4. 玩家按下 W、A、S、D 任意一个键算起跑（只认 W 的话，玩家可以只按 A/D 跑而不触发雪崩）：
   - 起跑提示用大约 1 秒慢慢淡出；
   - 计时器从这一刻开始算；
   - 屏幕中间偏上出现大号红色雪崩倒计时 3 → 2 → 1，上方小字"雪崩倒计时"，每跳一个数字放大一下；
   - 右上角出现画中画（见 5.3）。
5. 倒计时归零：显示"雪崩来了！"约 1 秒，屏幕边缘闪一下白色雪雾，镜头轻震，雪崩开始推进。

### 5.2 新手引导

- **触发**：第一次打开游戏时自动播放，"已看过"记录在浏览器本地（换浏览器或清缓存会再出现一次）；主菜单常驻"新手教程"按钮，可以随时重看。
- **流程**（共 5 步，顶部小圆点显示进度）：每一步都有"下一步"和"跳过"，看完回到主菜单，由玩家自己点"开始"。
  1. **游戏目标**：一张示意图（左上起点滑雪站 → 下坡 → 右下终点线，身后追着雪崩）。文字：按 W 起跑，3 秒后雪崩冲下来、越来越快，冲过终点线就赢、被追上就结束；躲开障碍物（树、石头、小木屋、缆车塔架会大幅减速，滑雪板可以撞飞）；屏幕上方进度条和离雪崩的距离怎么看。
  2. **操作方式**：按键图（见下）。
  3. **怎样跑得更快**：2D 侧视动画（见下）。
  4. **空中耍酷与得分**：两张卡片——点按空格摆姿势（0.8 秒，+150）、长按空格做动作（1.25 秒，+400）。文字：连着做倍率 ×1.5 / ×3、最高 20 倍、落地清零；没做完就落地速度只剩三成，来不及就按 Shift 取消；其他得分（每秒 +10、完美落地 +100、冲线 +1000、雪橇车 +500）。
  5. **雪橇车**：五档速度示意图（350 → 420 → 500 → 600 → 700，越来越高、越来越金）。文字：全程 4 间发光的小木屋，碰到光圈进屋、3 秒后骑车冲出（+500）；速度锁定只管转向，用 10 秒，冲出后 1.5 秒无敌；空中每做完一个动作 +1500 并升一档；硬着陆、失误或撞大障碍只炸掉车、人不减速；骑车碰到新木屋会换新车、从 350 重来。
- **按键图**：用 SVG 画的键盘加鼠标示意图。主要操作画大并高亮：W A S D 移动、鼠标转向、空格跳、Shift 或右键俯冲；Shift 的说明加上"耍酷时按下取消"，空格写"跳 / 耍酷"；下方小字：← → 也能转向、Esc 暂停、R 重新开始、M 静音。调试用的 ` 键不放进教程。
- **玩法动画**：2D 侧视示意动画，循环播放，配色和游戏一致（暖白 = 下坡、冷蓝 = 上坡）。
  - 正确示范：跑向崖边 → 腾空 → 按住 Shift 俯冲（小人前倾发光，Shift 键高亮）→ 落在暖白色下坡 → 完美落地，速度 120 → 250 km/h，然后肚皮滑行。
  - 错误示范：同样腾空俯冲，砸在冷蓝色上坡 → 硬着陆，速度掉到约 60 km/h。
  - 不新增"调整身体角度"之类的操作：完美落地的判定规则不变（见 3.2）。
- **主菜单**：只保留标题、副标题、"开始"、"新手教程"和诀窍提示（包括耍酷的说明）；面板放在画面一侧，让出滑雪站和山脉的画面。

### 5.3 画中画：滑雪站被雪崩淹没

- 用第二台镜头实时渲染同一个场景：滑雪站就是游戏里那一座，雪崩就是追你的那一场，不是预先做好的动画。
- 按下 W 起跑时出现在画面右上角，宽约 360、高约 200 像素（屏幕小时按比例缩小），圆角边框，标签"滑雪站"。
- 镜头固定在滑雪站侧前方，框住木屋和后面的山坡。
- 3 秒倒计时结束时，雪崩从滑雪站后方的山坡冲下来，大约 2 秒内把滑雪站整个淹没；淹没后再停留约 1.5 秒，然后淡出。全程约 7 秒。

### 5.4 终点环绕镜头

- 冲过终点线的那一刻胜利就锁定了，计时也停在这一刻。
- 角色自动刹车，在 1～2 秒内缓慢滑行停下，不再响应移动操作；停稳后开心地原地蹦两下、拍拍鳍翅。
- 从冲过终点的那一刻开始，镜头就绕着角色转一圈 360°（约 4 秒，距离约 5 米、略高于角色），转完后显示结算界面。
- 雪崩停止推进并淡出，不会在动画里把玩家吞掉；画中画如果还在也一起关掉。
- 动画期间隐藏速度等 HUD，顶部显示"抵达终点！"，画面下方显示"按任意键跳过"。按键盘任意键或点击鼠标，立刻跳过并显示结算界面（冲线时一直按着的键不算）。

### 5.5 被雪崩吞没的动画

- 被吞没的那一刻，角色和脚下的影子立刻隐藏，吞没点炸开一团雪粉，掩盖消失的那一下；雪印保留，随地面一起被盖住。
- 镜头在约 0.8 秒内迅速往上、往前（下坡方向）拉到离吞没点约 85 米高、65 米远的空中，之后继续缓缓往前飘，一边升一边回头对准吞没点；之后停在空中，带一点轻微震动，看着雪浪从吞没点碾过去、继续往前推。
- 吞没后停留 2.5 秒（镜头移动包含在内），然后显示结算。
- 和终点动画一致：隐藏速度等 HUD，顶部显示"被雪崩吞没"，下方显示"按任意键跳过"，按任意键或点击鼠标立刻显示结算。

## 6. 关卡设计：开放雪原

### 6.1 地图结构

- **形态**：一条有大方向的宽阔雪原带，宽约 500 米，整体往前方下坡，平均坡度约 10°（原来 6°，曾改为 16°，按作者实测调成 10°）。玩家可以横向自由跑、自己选路线，雪崩从身后追来。参考 Haste 的关卡结构。
- **边界**：越往两侧地势越高，最后变成很陡、爬不上去的雪山，自然地把玩家挡在地图里。
- **起点**：山腰的滑雪站（见 8.4），周围是一块平地。滑雪站后方的山坡一路往上，连到背景里高耸入云的山脉。
- **终点**：横跨整个地图宽度的终点线，正中间立着传送门和一道从很远就能看到的高光柱。跑过终点线的任何位置都算到达，不必穿过传送门的圈。
- **终点站**：终点线后面约 70 米，正中间，和起点同一套风格的滑雪站（见 8.4），周围压出一块平地。
- **终点后方**：地形往终点后面延伸约 600 米，坡度逐渐放缓成一片平缓的山谷，撒一些雪松；更远处是一排雪山和一层云，挡住地平线（比起点身后的山矮一些）。
- **缆车**：一条缆车线从山顶经过起点站，然后在整个场地里左右来回折返（Z 字形）：共 12 段，每段往前约 250 米，左右各到离中线 160 米处，最后进到终点站。塔架约每 55 米一根，可跑区域里约 80 根，有碰撞（算大障碍物）；缆绳和缆车厢挂在约 8～11 米高的空中，没有碰撞。障碍物会避开缆车线 20 米以内的地方。
- **进度**：顶部进度条按"往前跑了多远"计算。

### 6.2 地形生成：噪声打底 + 地形特征

1. **底层**：用噪声生成连绵起伏的雪坡（几种尺度的起伏叠加），整体往前下坡。
2. **地形特征**：每往前约 180 米放一排，每排 2～4 个特征，横向位置随机分布在地图宽度内。每一段都能挑路线，比如左边是跳台、右边是雪包群、中间是平缓的长坡。
3. **难度递增**：越往后，跳台越高、悬崖越深、雪包越大。
4. **起点附近**不放特征，起伏也压平，给玩家起跑的空间。
5. 同一个地图种子生成同一张地图；种子在调参面板里可以改。

### 6.3 地形特征库（第一版 5 种）

| 特征 | 形状 | 玩法 |
|---|---|---|
| 跳台 | 短陡的上坡，坡顶突然截断，后面接下坡 | 飞出去后俯冲，落在后面的下坡上 |
| 悬崖落差 | 一段比周围高、几乎水平的台地，前端突然下降，下面接下坡 | 俯冲加完美落地，爆发加速（教程演示的就是它） |
| 雪包群 | 一片连续的圆雪包 | 节奏：一个接一个地起跳、落地 |
| 大碗 | 一个大凹坑，前方坑沿带一道小唇 | 冲下去加速，再从另一边冲上来起飞 |
| 山脊 | 一道横着或斜着的长脊，迎面缓、背面陡 | 冲上去能飞出去很远 |

### 6.4 场景物件和障碍物

- **背景**：两侧雪山上不放树，只有岩石；滑雪站周围和身后山坡上的雪松保留。
- **障碍物**（碰撞规则见 3.4）：插在雪里的滑雪板（成对、交叉）、雪松、石头。动物暂时去掉。小木屋改成雪橇车增益，只放 4 间，见 3.8。
- **尺寸**：在原来基础上放大到 1.5 倍：雪松 9～14 米，滑雪板 2.7 米（卡通比例），石头直径 3～8 米；碰撞范围一起放大。
- **数量**：全图约 350 个（原来约 140 个）。一小片一小片地放，比如 5～10 棵树组成的小树林、一片石头、一排滑雪板；在地形特征的排与排之间撒下，越往后越密。
- **避开**：起点附近、地形特征的范围（包括跳台和悬崖的落地区），以及终点线前后。
- 雪崩经过时，障碍物和其他物件一样被埋掉。

## 7. 计分与结算

### 7.1 分数

| 来源 | 分数 |
|---|---|
| 时间 | 从起跑开始每秒 +10，冲过终点或被吞没时停止 |
| 完美落地 | +100 |
| 完成一个姿势 | +150 |
| 完成一个动作 | +400 |
| 冲过终点 | +1000 |
| 拿到雪橇车 | +500（见 3.8） |
| 骑雪橇车完成一个动作 | +1500（代替 400，乘耍酷倍率，见 3.8） |

- **连续耍酷的倍率**（同一次腾空内）：每完整做完一个姿势，后续的姿势和动作 ×1.5；每完整做完一个动作，后续 ×3。倍率连乘，最高 20 倍。完美落地的 100 分也乘上这次腾空攒下的倍率。落地后倍率清零，下次腾空从 1 倍开始；失误落地时，这次腾空已经拿到的分数保留，但完美落地不成立。
- **显示**：画面左上角、喇叭按钮右边显示"分数"（倍率大于 1 时旁边显示当前倍率）；每次加分时，屏幕中间偏下弹出一行"+150 大字展翅"这样的提示，往上飘并淡出。
- 不管是冲过终点还是被吞没，本局分数都算数。

### 7.2 结算界面

- 标题下方是一条完成进度条，每次进入结算时从 0 平滑涨到这局的进度（约 1 秒）；"你跑完了 xx%"（冲线时是"用时 xx 秒"）放在进度条下面。冲过终点时进度条涨满 100%，随后在进度条最右端弹出一颗旋转着放大的金色星星。
- 顶部用大字显示本次分数，下面一行小字写"历史最高 xx"；打破纪录时显示"新纪录！"。
- 历史最高分只记一个全局的（不按地图种子分开），存在浏览器里。
- 原有统计保留：用时、完成进度、平均速度、最高速度、完美落地、硬着陆；另加"完成姿势 x 次""完成动作 x 次"。
- **最短用时**：统计表"用时"那一行的右边写"最短 xx s"。只有冲过终点的局才计入；还没冲过线时显示"最短 —"；这局刷新了最短用时，就在后面标"新纪录"。全局只记一个，存在浏览器里。
- 以后可以考虑：S / A / B / C 评级。

## 8. 视听风格

### 8.1 美术

- **风格**：低多边形，加柔和渐变的天空和雾气。参考《风之旅人》、Haste。
- **原则**：形状简洁，靠色彩和光影营造氛围。美术资源少，浏览器渲染也轻。
- **雪地场景**：
  - 地面是低多边形的白色雪地；朝阳的下坡带一点暖色（淡淡的桃色），背光的上坡是冷蓝色的阴影，保留"暖色 = 下坡"的提示；很陡的雪山侧壁偏岩石的灰蓝色。
  - 天空是淡蓝灰色，地平线附近偏白；雾是白色的，远处的山慢慢消失在雪雾里；保留一点低角度的暖阳。
  - 主角的配色不变。

### 8.2 速度感

- 视野（FOV）随速度拉大
- **飘雪**：镜头周围始终飘着一层小雪，密度不大。站着不动时雪花慢慢往下飘；跑起来以后雪花相对你往后飞；速度越快，雪花被拉成越长的白色细线，像穿过雪幕。
- 高速时屏幕边缘加风雪速度线
- **雪印**：主角经过的地面留下一道连续的、略微凹陷的浅蓝灰色雪痕。小碎步跑时窄一些（约 0.35 米），肚皮滑行时宽一些（约 0.75 米），在空中时断开。一局里一直保留，最多保留最近约 2 公里，更早的从尾部慢慢消失；雪崩经过的地方雪印会和地面一起被盖住。
- **雪粉**：肚皮滑行速度够快时，身后扬起少量雪粉
- 风声随速度变大
- 完美落地时镜头冲击、音效和粒子特效

### 8.3 音乐和音效

**来源**：全部用浏览器的 Web Audio 实时合成，不用音频文件，没有版权问题，还能随速度和雪崩距离实时变化；音质偏电子合成器风格。整套音频系统（音量、混音、随状态变化的逻辑）和声音来源分开，以后想换成更好的素材，只需要替换声音来源。

**音乐**（按场景分层，随游戏状态实时变化）：

| 场景 | 音乐 |
|---|---|
| 主菜单、新手引导、起跑前 | 安静的氛围音乐：柔和的长音铺底，加一点像风铃一样的旋律 |
| 奔跑中 | 轻快的电子节奏；速度越快，鼓点越密、音色越亮 |
| 雪崩逼近（80 米以内） | 叠加一层低沉、紧张的鼓和低音，越近越响 |
| 冲过终点 | 一段 2～3 秒的胜利小旋律，然后回到轻柔的氛围音乐 |
| 被吞没 | 一个低沉的下行音效，音乐淡出 |

**音效**：
- 界面：按钮点击；倒计时 3、2、1 各一声"嘀"；"雪崩来了"时一声低沉的轰鸣
- 角色：小碎步的踩雪声（随步频）；肚皮滑行的沙沙声（随速度变响）；起跳的"呼"声；俯冲时音调逐渐升高的风啸声
- 落地：普通落地一声闷响；完美落地一声清脆的"叮"加加速的"嗖"；硬着陆一声重重的撞击
- 障碍物：撞上大东西一声"咚"；撞飞滑雪板一阵"哐啷"声
- 环境：一直存在的风声，速度越快越大、越尖；雪崩的轰鸣持续循环，越近越响
- 结局：冲过终点的号角；被吞没时一声雪浪盖过来的"轰"

**音量控制**：画面左上角一个小喇叭按钮，点一下静音或取消静音，也可以按 M 键切换；暂停菜单里有"音乐音量"和"音效音量"两个滑块，默认 70%；设置记在浏览器里。

**开始播放**：浏览器规定用户点击页面之前不能播放声音，所以第一次点击页面（比如新手引导里的"下一步"或主菜单的"开始"）之后才开始播放菜单音乐。

### 8.4 主角：企鹅少女

参考图：用户提供的三视图（正面、侧面、背面），严格按图复刻。下列尺寸是从三视图上量出、按总高 1.4 米换算的。

**造型**

| 部位 | 做法 |
|---|---|
| 整体 | 总高约 1.4 米；头连头发高约 0.58 米（约占 42%），头发最宽处约 0.6 米，和身体一样宽 |
| 身体 | 全身奶油色（背面也是），圆润的蛋形、前后略扁，宽约 0.6 米，低多边形大块三角切面；下巴完整露在身体上方 |
| 鳍翅 | 黑色细长条，从脖子下方贴着身体侧面一直垂到接近脚的位置，中段顺着身体往外弯 |
| 脚 | 两只橙色蹼足，短，从身体下方往前伸出 |
| 头发 | 银色蓬松波波头：头顶圆，两侧比脸宽出一大截；刘海是几缕较宽的发束，中间有缝隙、发梢尖尖，只到眉毛和眼睛上沿，不遮眼睛；耳朵前一缕细发束垂到下巴；后发垂到身体上，中间最长。做成带发束棱线和锯齿发梢的外壳，底下的头骨用头发颜色盖住，不做物理摆动 |
| 脸 | 动漫脸型：上半部圆、脸颊圆润、最下面收成小尖下巴（不是正圆）。五官画成贴图：动漫眼，虹膜几乎占满眼眶、只在两侧露一点眼白，上深下浅的棕红色，左上两个高光、右下一个；上睫毛粗黑、比眼睛宽，外眼角带下垂的小尾巴；有双眼皮线和外眼角的下睫毛；眼睛又大又分得开、位于脸的偏下部分；刘海在额头投下淡淡的阴影；粉色腮红；嘴几乎贴着下巴；鼻子几乎看不见。皮肤几乎均匀受光，没有明暗分界。侧面能看到脸颊、眼睛和耳朵 |
| 不做 | 三视图胸口的小灰点 |

**渲染**：身体、鳍翅、脚用卡通明暗加平面着色，切面分明；头和脸用平滑的卡通渲染，皮肤明暗对比较柔和，避免脸上出现硬阴影；头发是带棱角的卡通渲染。

**实现**：全部用 Three.js 代码拼出来（`src/character.js`），不依赖建模软件。纯视觉，碰撞和物理不变。在地面上时，角色的"上"方向贴合脚下地面的法线（陡坡上不会埋进地里），离地后慢慢回到竖直。

**动作**

| 状态 | 表现 |
|---|---|
| 起跑前 | 正面朝向镜头；身体轻微呼吸起伏、鳍翅小幅摆动、每隔几秒眨眼 |
| 起跑 | 0.25 秒转身 180° 朝前 |
| 低速 | 小碎步摇摆跑，两脚交替，身体左右晃，速度越快步频越快 |
| 高速 | 超过约 90 km/h 扑倒肚皮滑行，鳍翅向两侧张开保持平衡，脚翘起；降到约 75 km/h 以下才站起来（防抖），切换有约 0.2 秒过渡 |
| 空中 | 鳍翅张开 |
| 俯冲 | 身体慢慢转向运动方向（越俯冲越朝下，最多约 80°，见 3.5），鳍翅往后贴紧身体，身体发出淡淡的暖光 |
| 落地 | 完美落地压扁再弹起；硬着陆压扁得更明显，并在硬直期间保持 |
| 表情 | 只有微笑加眨眼（游戏中看不到脸，以后做结算正面镜头时再加表情） |

**镜头**：主菜单时镜头回看滑雪站，角色面向镜头；起跑前角色正面朝镜头；起跑后是背后视角，俯冲时往下多看约 12°；冲过终点后环绕角色一圈（见 5.4）。默认镜头距离 5.5 米。

### 8.5 起点：山腰的滑雪站

## 9. 技术方案

| 项目 | 选择 | 理由 |
|---|---|---|
| 引擎 | **不用游戏引擎** | 网页优先，靠链接传播，加载速度很要紧 |
| 3D 渲染 | Three.js | 网页原生，核心库体积小，打开就能玩；生态大、资料多 |
| 构建工具 | Vite | 开发时改完代码浏览器即时刷新，打包产物是静态文件 |
| 角色控制 | 自己写运动学控制器（查询地面高度和法线，自己算速度和重力） | 手感完全可控，不用完整的物理引擎 |
| 地形 | 高度用解析函数计算（噪声 + 地形特征 + 两侧雪山），物理和网格用同一个函数；网格按区块加载，远处用更粗的网格，身后销毁 | 开放地图面积大，必须分块和分级细节才能保证帧率 |
| 雪崩掩埋 | 在地形的顶点着色器里把雪崩线后面的地面抬高、抹平成厚雪 | 不用重建网格，开销小 |
| 画中画 | 同一个渲染器用第二台镜头渲染到右上角的一块视口 | 实时，和主画面完全一致 |
| 部署 | GitHub Pages（推送 main 后由 GitHub Actions 自动部署） | 免费，生成公开链接 |

**为什么不用 Unity / Godot / Unreal**：Unreal 已经不支持导出网页；Unity 和 Godot 导出的网页包体大（约 10MB 起），加载慢，而且很多工作要在编辑器里手动操作。这个项目的角色控制和关卡生成本来就要用代码实现，引擎编辑器的优势用不上。

**性能目标**：主流 PC 浏览器上稳定 60 帧，首屏加载在 3 秒以内。

**调试**：调参面板和左下角调试信息默认隐藏，按 ` 键显示；调参面板显示时放在画中画下方。

## 12. 风险与对策

| 风险 | 对策 |
|---|---|
| 一局 3～5 分钟，后期被吞掉很挫败 | 前期雪崩放慢；结算显示完成进度；如果试玩反馈仍然太挫败，在中段加检查点，或者把单局缩短到 2～3 分钟 |
| 核心手感不好玩 | 先验证手感再加内容；用调试面板快速迭代 |
| 开放地图太空、没有方向感 | 每排都放地形特征；终点光柱从远处可见；飘雪和雪崩提供方向和速度参照 |
| 程序生成的地形平淡或出现怪形状 | 特征按难度曲线摆放；特征边缘平滑过渡到底层地形；调参面板可以换种子、调大小 |
| 开放地图面积大，帧率下降 | 地形分块加载、远处用粗网格、雪雾遮住加载边界；树木用实例化渲染 |
| 3D 迷向、镜头眩晕 | 镜头跟随要平滑，FOV 变化幅度要克制，可以加设置选项 |
